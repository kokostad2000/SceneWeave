## 9. 环境与沙箱说明（影响命令可复现性）

DSH 文件沙箱只允许写入本项目目录，因此 `uv` 与 `pnpm` 的默认全局缓存（`~/.cache/uv`、pnpm store）不可写。实际执行时重定向到项目内：

```bash
export UV_CACHE_DIR=<repo>/.cache/uv          # 155 MB，已在 .gitignore 中
pnpm install --store-dir <repo>/.cache/pnpm-store
```

`scripts/export_contracts.sh` 本身不含该重定向；在无沙箱限制的机器上直接执行即可，在受限环境下需先导出上述变量。`backend/.venv`（34 MB）与 `frontend/node_modules`（134 MB）均在项目内，未触碰系统环境。
